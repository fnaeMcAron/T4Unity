# TIMELESS

Слешер для обучения Unity и его API.
## Реализовано
##### Архитектура
Менеджер персонажей - базовый персонаж - наследники базового персонажа. 
Используются стейты для более простого отслеживания что именно сейчас нужно делать
##### Система стиля с изменением разрешения рендера
Чем выше стиль на Родионе, тем хуже разрешение рендера
##### Базовый скрипт врага
Следует за игроком, может получать урон и станиться
##### Музыкальные баффы
В зависимости от выбранной музыки у Ёки персонажи будут получать разные баффы
##### Использование новой системы ввода 
Есть различие между зажатой и нажатой кнопкой
